# Recipe for Qwen/Qwen2.5-1.5B-Instruct

Generated by canifinetune 0.4.0. `train.py` and `eval_smoke.py`
call the installed package's shared runtime; keep this version installed.
No model weights were downloaded during generation.

Install `requirements.txt` in a fresh Python 3.12 environment. Use the CUDA 12.4
wheel for verified CUDA training, or the CPU wheel for a tiny fp32 full/LoRA run.
The project README contains separate environment setup for Windows and Linux.

```console
python -m pip install -r requirements.txt
python train.py --config config.yaml
python eval_smoke.py --output-dir output --max-new-tokens 8
```

Run from this folder, or pass the config/output paths explicitly from elsewhere.
Data and output paths in the config are resolved relative to the config file.
Command-line path overrides are relative to the calling shell's directory.
Choose an empty output for each run. Existing artifacts are never overwritten.

- `config.yaml`: validated configuration (JSON is also valid YAML).
- `data/sample.jsonl`: four short synthetic instruction records; smoke only.
- `dataset_format.md`: exactly the data processor's supervision contract.
- `expected_vram.md`: static planning budget and its limitations.
- `run.sh`: Linux convenience smoke wrapper.
- `output/run.json`: outcome, effective config, dataset statistics and measurements.
- `output/adapter`: created only after successful training and saving.

Default objective is full-token causal loss. `loss_mode: assistant` is opt-in.
Long rows fail unless `truncation: right` is explicitly set and supervision survives.
No records are silently dropped. This is not a complete training-resume checkpoint.
Liger is experimental; its stock loss estimate is a conservative proxy, not a
fused-kernel accuracy measurement. See `troubleshooting.md` for failure states.
